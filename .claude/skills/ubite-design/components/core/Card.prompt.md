Surfaces and section headings.

```jsx
<Card elevation={1} padding="md">…</Card>
<Card elevation={2} radius="lg" padding="xl">…</Card>
<SectionHeader title="Fel principal" meta="4 feluri" density="zone-2" />
```

Never add a border or a shadow to a card — the whole system separates layers by colour value. Only two elevations exist.
