The chosen UBite lockup as a drop-in — the tray-U followed by "Bite", drawn by `Logo`.

```jsx
<Wordmark size={28} />                {/* app header */}
<Wordmark size={48} variant="mark" /> {/* app-icon tile: the lockup on the accent square */}
<Wordmark size={20} tone="mono" />    {/* print, single-colour contexts */}
```

Vector files for everything outside React (store listing, print, social) are in the repo's `assets/brand/`: `logo.svg`, `logo-on-dark.svg`, `logo-white.svg`, `logo-mono.svg`, `app-icon.svg`, the PWA PNGs and `favicon.svg`. A University of Bucharest mark, if one is ever mandated, sits **beside** this lockup with clear space — never merged into it.
