# DCCAS dashboard — UI kit

Read-only. This is the screen that turns the canteen directorate from gatekeeper into ally, so
it opens with a sentence in plain Romanian rather than a grid of widgets.

- Four headline numbers: meals served, average wait, the share of students who say the app
  brought them, and the count **and cost** of free meals given.
- Footfall by day and average wait by hour.
- Best and worst rated dishes, each with its sample size, and a line making clear the worst list
  is a conversation with the kitchen, not a sanction.
- Portions prepared versus sold — shown **only** for dishes where staff filled the optional
  field. Where the data is missing the row is absent; nothing is estimated.
- Simple table export.

Files: `index.html`, `app.jsx`.
