# Staff menu editor — UI kit

One screen that exists to be finished in under two minutes, in a kitchen, on a shared account.

- Opens with **yesterday's menu already loaded** and marked as such.
- The full catalogue — 15 dishes, under the 40-item threshold — is a plain checklist. No search,
  because none is needed at that size.
- Price is prefilled from the catalogue and overridable. "Porții pregătite" is optional and
  never blocks publishing.
- One action publishes, and the confirmation says what just happened to whom: "312 studenți
  primesc o notificare."
- "Adaugă un fel nou" grows the catalogue through use, rather than through a setup phase.

Files: `index.html`, `app.jsx`.
